# Czym są wektory
Obiekty które można dodać/mnożyć przez liczbę, co daje nowy wektor, przykładem są zwyczajne liczby. Wektory znajdują się w przestrzeni wektorowej która może być dwuwymiarowa, trójwymiarowa itd.

# Kombinacje liniowe
${}\vec{a}, \vec{b}{}$
${}\vec{c} = x * \vec{a} + y * \vec{b}{}$
### Liniowa niezależność
Wektory liniowo niezależne to wektory których nie można przedstawić przez kombinację innych 
wektorów z tego samego zbioru wektorów.

${}x * \vec{a} + y * \vec{b} + z * \vec{c} = 0{}$, więc ${} x = y = z = 0{}$
# Iloczyn skalarny
${}\vec{a}, \vec{b}, \phi{}$
Kąt ${}\phi{}$ znajduje się pomiędzy vektorami ${}\vec{a}{}$ oraz ${}\vec{b}{}$.

${}\vec{a} * \vec{b} = \vec{a} \vec{b} = |\vec{a}| * |\vec{b}| * \cos \phi{}$
${}\vec{a}\vec{a} = \vec{a}^2 = |\vec{a}||\vec{a}| * \cos 0 = |\vec{a}|^2{}$

${}\vec{a} = [a_{1}, a_{2}, a_{3}]{}$
${}\vec{b} = [b_{1}, b_{2}, b_{3}]{}$
${}\vec{a}\vec{b} = a_{1}b_{1} + a_{2}b_{2} + a_{3}b_{3}{}$
# Iloczyn wektorowy
Wynikiem mnożenia dwóch wektorów iloczynem wektorowym będzie wektor.
${}\vec{c} = \vec{a} \times \vec{b}{}$
${}|\vec{c}| = |\vec{a}| * |\vec{b}| * \sin \phi{}$

${}\vec{c} \perp \vec{a}{}$
${}\vec{c} \perp \vec{b}{}$

$\vec{c} = \begin{bmatrix}  e_{1} & e_{2} & e_{3}\\a_{1} & a_{2} & a_{3} \\b_{1} & b_{2} & b_{3} \end{bmatrix}$

${}e_{1} = [1, 0, 0]{}$
${}e_{2} = [0, 1, 0]{}$
${}e_{3} = [0,0,1]{}$

${}\vec{c} = e_{1}a_{2}b_{3} + e_{2}a_{3}b_{1} + e_{3}a_{1}b_{2} - e_{3}a_{2}b_{1} - e_{1}a_{3}b_{2} - e_{2}a_{1}b_{3}{}$
${}= a_{1}(a_{2}b_{3}-a_{3}b_{2}) + e_{2}(a_{3}b_{1} - a_{1}b_{3}) +e_{3}(a_{1}b_{2}-a_{2}b_{1}) {}$
${}= [a_{2}b_{3} -a_{3}b_{2};a_{3}b_{1}-a_{1}b_{3};a_{1}b_{2}-a_{2}b_{1}]{}$

Symbolem ${}|\vec{a}|{}$ oznaczamy długość wektora w iloczynach.

## Przykładowe zadanie
${}\vec{p} = (1, 8){}$
${}\vec{q} = (2,-3){}$

${}\vec{q} = \vec{q'} + \vec{q''}{}$
${}\vec{q'} \parallel \vec{p}{}$
${}\vec{q''} \perp \vec{p}{}$

${}\vec{q''}\vec{p} = 0{}$
${}\vec{q}\vec{p} = (\vec{q'}+\vec{q''})\vec{p}{}$
${}=\vec{q'}\vec{p} +\vec{q''}\vec{p} = \vec{q'}\vec{p}{}$
${}=|\vec{q'}| * |\vec{p}|{}$

${}|\vec{q'}| = \frac{\vec{q}*\vec{p}}{|\vec{p}|}{}$

${}\vec{a} = |\vec{a}| * \hat a{}$
${}\hat a = \frac{\vec{a}}{|\vec{a}|}{}$

${}\vec{q'} = |\vec{q'}| * \hat q' = |\vec{q'}| * \hat{ p} = |\vec{q'} * \frac{\vec{p}}{|\vec{p}|}{}$
${}= \frac{\vec{q}\vec{p}}{|\vec{p}|} * \frac{\vec{p}}{|\vec{p}|} = \frac{\vec{q}\vec{p}}{\vec{p}^2} * \vec{p}{}$
${}\vec{q''} = \vec{q}-\vec{q'}{}$
